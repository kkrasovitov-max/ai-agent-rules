# AI Agent Rules — центральная база инструкций

## Назначение

Данный репозиторий является единым источником общих инструкций, стандартов и схем работы для ИИ-агентов, участвующих в разработке и обслуживании проектов.

## Порядок работы ИИ-агента

1. Определи, какая схема работы используется в текущем проекте.
2. Прочитай соответствующую инструкцию полностью.
3. Изучи применимые дополнительные правила из директории rules.
4. Изучи индивидуальные инструкции текущего проекта.
5. Выполняй задачи согласно выбранной схеме работы.

Если схема работы не указана, уточни её у пользователя.

## Общие обязательные правила

- Не изменяй файлы, не относящиеся к задаче.
- Не перезаписывай существующие изменения пользователя.
- Не редактируй production-код напрямую.
- Проверяй изменения перед деплоем.
- Не выполняй опасные операции без согласования.
- Не раскрывай пароли, токены и SSH-ключи.
- Не перезаписывай рабочую базу данных локальной копией.
- Обеспечивай возможность отката изменений.
- Не придумывай результаты проверок и выполненных операций.
- Не изменяй инструкции данного репозитория без разрешения владельца.

## Приоритет инструкций

Индивидуальные инструкции проекта определяют его технические особенности и выбранную схему работы.

Общие инструкции определяют стандартный порядок работы.

При обнаружении противоречий сообщи пользователю. Не обходи ограничения безопасности и прав доступа.

Если необходимый файл инструкции недоступен, явно сообщи об этом.

## Основной принцип

Все изменения должны быть контролируемыми, проверяемыми и по возможности обратимыми.
